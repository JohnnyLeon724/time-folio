# Timefolio v0.1.0

首个测试版本，用于记录工作、学习及其他活动的时间投入。数据保存在本机，使用前请在设置中确认统计时区。

## 功能

- 分段计时：开始、暂停、继续、结束后核对，支持最近任务标题复用。
- 时间日历：月、周、列表视图，手动补录，冲突定位与未保存修改保护。
- 时间报告：周报、月报、日期筛选、时间明细与按标题汇总。
- 数据管理：整月 CSV、完整 JSON 备份、本地快照及回收站。
