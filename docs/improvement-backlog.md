# Timefolio 功能与体验优化清单

未保存修改保护、时间冲突定位、时间录入提速、图表明细联动和备份状态反馈已实现。整月导出已明确范围，筛选结果导出仍为可选扩展。桌面跨平台实机验收仍待完成，测试证据见[发布验收记录](release-checklist.md)。

本文整理 2026-10-03 的代码审阅建议，供后续排期使用。已实现条目在下文标明，其余条目仍待实施或验证。现有功能说明见 [README](../README.md)，测试与发布状态以[发布验收记录](release-checklist.md)为准。

## 编辑安全与录入效率

### 未保存修改保护

现状：[编辑面板](../src/features/entries/entry-sheet.tsx)比较标题、备注、时段和核对选项，关闭存在未保存修改的面板前要求确认。保存期间禁止重复提交和关闭，失败后保留输入。

关闭确认默认聚焦“继续编辑”，选择“放弃修改”才会关闭。当前保护限于面板内存中的输入；持久化草稿可另行设计，避免把草稿误当成已确认工时。

验收标准：

- [x] 未修改内容时可直接关闭，不额外打断操作。
- [x] 修改后通过关闭按钮、Escape、遮罩或取消离开时，执行一致的保护逻辑。
- [x] 选择继续编辑后，输入、时段和核对选项保持不变。
- [x] 保存成功后正常关闭；保存失败后仍能修改并重试。
- [x] 正在保存时不能重复提交或绕过已有关闭限制。

### 时间冲突定位

现状：[后端冲突校验](../src-tauri/src/domain/validation.rs)返回当前时段 ID、冲突时段 ID、记录 ID、标题及起止时间。编辑面板高亮对应时段，并显示统计时区中的完整日期和时间；记录内部重叠会标出双方时段。

外部冲突可打开[只读详情](../src/features/entries/conflict-record-dialog.tsx)，返回后保留当前输入。详情读取失败可重试，记录不存在时明确提示。修改时段后清除过期提示，再次保存仍由后端最终校验，不自动裁剪或覆盖已有工时。

验收标准：

- [x] 明确指出当前哪一段与哪条记录重叠，并按统计时区显示时间。
- [x] 查看冲突记录时，不丢失当前未保存输入；与修改保护协同处理。
- [x] 修正时段后能重新提交，清除过期提示。
- [x] 跨午夜、多时段、同名任务仍能准确定位。

### 时间录入提速

现状：[日期时间组件](../src/components/date-time-picker.tsx)支持直接输入 `HH:mm` 或 `HH:mm:ss`、时分秒下拉选择、前后调整 5 分钟或 15 分钟。直接输入在失焦或 Enter 时应用，非法输入就地提示并阻止保存；尚未应用的输入也受关闭保护。

输入到分钟时保留原秒数。快捷调整采用日历时间运算，跨午夜同步改变日期；最终仍由后端按统计时区解析并处理夏令时歧义。新增时段从上一段结束时间开始，默认持续 1 小时；无前段时使用所选日期的 09:00 至 10:00。

验收标准：

- [x] 直接输入、下拉选择和快捷调整使用同一份表单值。
- [x] 保留已有秒级数据，不因只编辑分钟而无提示地清零秒数。
- [x] 不合法输入有就地提示，不能保存结束早于开始的时段。
- [x] 跨午夜时日期明确变化，按统计时区解析，保持现有夏令时歧义处理。
- [x] 新增时段不会静默覆盖已有时段，保存时仍校验重叠。

## 报表与数据反馈

### 图表与明细联动

现状：[每日工时图表](../src/features/reports/daily-duration-chart.tsx)可点击柱形筛选日期，也提供可用键盘操作的日期下拉选择。[工作明细](../src/features/reports/work-details-table.tsx)自动展开对应日期，同时保留任务搜索条件，并显示清除日期筛选入口。

切换月份或统计时区重置日期和任务筛选。待核对统计区域的“查看待核对记录”按钮进入核对列表。

验收标准：

- [x] 鼠标和键盘都能选择日期、清除筛选。
- [x] 日期筛选与任务搜索共同生效，分页回到有效页。
- [x] 切换月份后不保留不适用的日期筛选。
- [x] 无匹配记录时说明原因，不能表现为加载失败。

### 搜索与导出范围提示

现状：工作明细搜索和日期筛选只影响表格；[导出入口](../src/app/app.tsx)调用整月导出，按钮文案为“导出整月”。按钮旁显示月份、整月时段数量，并明确说明筛选不影响导出。没有已确认时段时禁用导出。

可选扩展：“导出当前筛选结果”尚未实施。如增加此操作，需让筛选条件成为明确的导出参数，并统一界面与后端的过滤规则；以下筛选导出标准仍待该扩展实施时验证。

验收标准：

- [x] 导出前可辨认月份、整月范围及工作时段数量。
- [ ] 筛选导出包含全部匹配时段，不仅是当前分页中显示的行。
- [x] 保持现有中文五列、每时段一行、跨午夜拆日及文本转义规则。
- [ ] 导出的时段与界面筛选结果逐项一致，精确时长保持一致。

### 备份状态与失败反馈

现状：[设置页](../src/features/settings/settings-page.tsx)分别显示快照加载中、空列表和读取失败，失败可重试；最近本地快照时间取自成功读取的列表。完整备份区域显示这台设备最近成功导出的时间，来源为后端在成功写入备份后保存的设备元数据。

创建、删除、恢复后刷新快照列表；工作区变化或窗口重新获得焦点时也重新读取。操作成功与后续列表刷新失败分别反馈。外部备份和仅保存在本机的快照分别标注。

验收标准：

- [x] 读取失败显示错误及重试入口，不显示为空列表。
- [x] 最近成功时间来自实际成功结果，不在失败时更新。
- [x] 创建、删除、恢复后刷新列表，读取失败时显示错误。
- [x] 快照轮替和失败保留旧文件等专项检查，统一记录到发布验收清单。

## 后续功能与性能

### 最近任务与快捷复用

现状：[计时输入](../src/features/timer/timer-card.tsx)支持搜索最近任务标题，也可继续自由输入。建议按记录创建时间倒序排列，排除已删除记录；去除首尾空格后按完全相同的标题去重，每次最多显示 8 项。搜索忽略大小写，先筛选再限制数量。

使用方向键选择建议，Enter 填入标题，再按 Enter 或点击开始创建新记录；点击建议也只填入标题。标题仍可编辑，Escape 或离开输入框收起建议。只复用标题，不复制旧时段或核对状态。有正在计时或暂停的任务时不展示新任务输入。

验收标准：

- [x] 可以搜索和键盘选择最近任务，也可以继续自由输入。
- [x] 同名标题合理去重，标题仍可编辑。
- [x] 开始计时生成新记录，不修改原任务记录。
- [x] 有活动任务时保持现有单一活动记录约束。

### 周报与任务汇总

现状：[报告入口](../src/features/reports/reports-page.tsx)支持周报和月报切换。周报可选择周内日期、切换上一周或下一周、回到本周，并显示完整起止日期。每周起始日沿用工作区设置；后端与月报共用统计时区、已确认记录规则及每日边界切分，跨月周保持完整七天。图表和明细沿用日期筛选、任务搜索及原记录编辑入口，读取失败可重试。CSV 导出仍只在月报提供。

现状：[按标题汇总](../src/features/reports/title-summary.tsx)在周报和月报中合计当前完整周期的已确认时长。去除首尾空格后完全同名的记录归为一组，区分大小写；仅聚合展示，不合并原记录，也不建立独立任务身份。分组按累计时长降序排列，同一原记录的跨日片段合计时长但只计一次记录数。展开后可逐条打开原记录，显示的累计时长仅限所选周期。

标题可搜索，标题列表和组内原记录均每页最多显示 8 项。明细搜索与日期筛选不改变汇总范围，界面明确说明此规则；切换周期或统计时区重置汇总搜索和展开状态。项目、标签及独立任务身份仍属于后续扩展。

验收标准：

- [x] 周、日及月汇总使用同一统计时区和已确认工时规则。
- [x] 跨周、跨月时段按边界正确切分，汇总不重复累计。
- [x] 按标题汇总支持追溯原始记录，明确同名标题的归组方式。

### 历史数据性能优化

现状：[记录读取](../src-tauri/src/db/records.rs)查询全部工作记录；[工作区接口](../src-tauri/src/commands/mod.rs)将记录交给前端使用。长期积累后的性能影响尚未量化。

建议：先使用一万条合成记录测量启动、月份切换、搜索、报告生成及内存占用。根据瓶颈决定是否按日历可见范围读取、让核对与回收站独立分页，或继续拆分页面资源。

验收标准：

- [ ] 记录测试机器、数据分布及优化前后的测量结果，再确定性能目标。
- [ ] 日历按实际可见范围加载，跨月周视图不遗漏邻月记录。
- [ ] 分页或按范围读取不削弱全局时间冲突校验。
- [ ] 报告、导出与备份仍覆盖各自完整数据范围。

## 桌面验收与实施边界

桌面验收使用独立测试数据库，具体检查项和结果继续维护在[发布验收记录](release-checklist.md)，不在本文另建完成状态。重点覆盖托盘操作、休眠唤醒、异常退出恢复、备份恢复，以及在表格软件中打开 CSV。浏览器示例数据验证不能替代桌面实机操作。

每个独立功能完成后，连同必要测试原子提交；避免把编辑保护、报表交互和数据读取改造混在一次提交中。后续可根据实际使用反馈选择筛选导出或最近任务复用。涉及导出范围、任务身份或后端查询接口的变化，应先明确数据规则及兼容性，再开始实现。
