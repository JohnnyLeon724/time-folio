# Timefolio 黑白工作台设计

用户已确认直接实现：浅灰窄侧栏、白色内容区、顶部紧凑计时条、ReUI 月/周/列表日历、右侧编辑与核对面板。基础组件使用 shadcn/ui，日历采用 ReUI Radix Event Calendar。

## 视觉与布局

背景白色 #ffffff，侧栏和次级背景 #fafafa / #f5f5f5，主文字与主按钮 #171717，次级文字 #737373，边界 #e5e5e5。删除和错误保留语义错误色，状态同时提供图标与文字。正文使用系统中文无衬线字体，计时数字使用系统等宽字体和等宽数字。

桌面侧栏约 208px，可收起为图标栏；正文由页眉、紧凑计时条、简洁月度摘要、日历组成。移除装饰标语、虚构头像及装饰卡片。日历承担主要空间，分开的工作时段分别显示，午休保持空白。

编辑和核对使用右侧 Sheet，显示统计时区、实际时段、异常证据和保存操作。确认删除使用 AlertDialog。报告使用灰阶每日柱图和 shadcn Table。设置划分常规、备份与恢复两个页签。

## 数据与交互

保留 Rust 权威计时、报表与数据写入。日历 events 受控，按保存的统计时区展示。禁用拖动、缩放以及自动写入，点击记录进入原核对流程；补录仍通过后端校验。月份和选中日期协调，今天按钮必须定位今天所在周。用键盘可访问的月/周/列表切换与导航。

保留失败输入、幂等请求和旧表单修订。加载使用 Skeleton，空状态给出明确下一步，错误使用 Alert，成功通知使用 Sonner。小窗口使用收起侧栏和可滚动内容，表单在窄屏铺满可用宽度。

## 验证

测试覆盖日历时区与分段、今天定位、空列表、点击打开记录、中文输入法、计时失败保留输入、核对证据选择、侧边面板及设置页签。执行前端测试、类型检查、格式检查和生产构建；浏览器以合成数据进行 1180×820 与 900×600 视觉检查，合成预览不得访问真实桌面数据。
